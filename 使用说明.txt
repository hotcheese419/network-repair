网络修复 1.0
适用：Apple 芯片 Mac，macOS 14 或更高版本。

使用
1. 先断开 VPN，退出代理/加速软件，避免软件持续接管配置。
2. 双击桌面上的“网络修复”。打开时自动检查配置和网络连接。
3. 点击“修复网络”，在 macOS 授权窗口验证管理员身份。
4. 程序执行修复并复查网络，结果显示在窗口上方；“诊断详情与日志”可以展开。

点击“修复网络”会做什么
• 当前网络位置的普通网络服务：清除手动 DNS 与搜索域，恢复由网络提供。
• 同一范围：关闭 HTTP、HTTPS、SOCKS、PAC 及代理自动发现等系统代理开关；保留服务器地址、端口和绕过列表。
• hosts：将 /private/etc/hosts 恢复为 macOS 默认三条本地主机映射，自定义条目会移除。
• 刷新目录服务 DNS 缓存，通知 mDNSResponder 重新加载。
• 复查 DNS 解析及公开网站的 HTTPS 连接。

工具不会常驻后台，不保存管理员密码，不安装后台提权服务，也没有“恢复上次备份”功能。失败时会尝试在当前操作内自动回滚已改动的配置；若回滚失败，会在日志明确说明。

范围与提示
本工具处理 VPN/代理使用后常见的本机 DNS、hosts 和系统代理配置问题。Wi-Fi 未连接、路由器或宽带故障、需要网页认证、VPN 隧道或网络扩展仍在工作时，配置处理成功后也可能仍无法联网。它不自动删除 VPN、不修改固定 IP/路由，不清空 /etc/resolver，也不删除企业管理描述文件。

连通性检查会直接访问 Apple 和百度的固定公开 HTTPS 页面，不上传本机配置；绕过系统 HTTP 代理，VPN 隧道仍可能影响结果。单个站点受限不会直接判定全部网络中断。此结果不是所有网站可用性的保证。

界面
中文原生 macOS 窗口，跟随系统浅色/深色。Command-R 重新检查，Command-Shift-R 修复网络。修改操作使用系统自带管理员授权框。

构建
源代码包内运行 ./build.sh [输出目录]。
依赖仅为 Apple Command Line Tools 和系统框架，无需下载第三方包。
入口为 main.swift，核心为 ResetCore.swift，连通性检查为 NetworkDiagnostics.swift。
--inspect 与 --diagnose 只读；--self-test 使用隔离测试数据，不修改本机网络。--repair 需要 root，通过 GUI 请求系统授权。
